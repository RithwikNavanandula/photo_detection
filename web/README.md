# SBC Label Scanner — Next.js Frontend

Modern UI for the Label Scanner, talking to the Flask API (same origin via `/api` rewrite).

## Stack

- Next.js 15 + React 19 + TypeScript
- Tailwind CSS v4 + shadcn/ui
- TanStack Query + Zod
- IndexedDB local scans + PWA service worker

## Local develop

```bash
# terminal 1 — Flask API (from repo root = photo_detection/)
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python server.py   # :5000

# terminal 2 — Next UI
cd web
npm install
npm run dev        # :3000
```

Open http://localhost:3000

Optional: `FLASK_ORIGIN=http://127.0.0.1:5000 npm run dev`

## Production (Render)

Deploy the **photo_detection** GitHub repo (Docker). One service runs Flask on localhost:5000 and Next on `$PORT`, with Next rewriting `/api/*`.

### 1. Push this repo

```bash
git add -A
git commit -m "Add Next.js UI and Docker Render deploy"
git push origin main
```

### 2. Create the service

**Option A — Blueprint (recommended)**  
1. Render Dashboard → New → Blueprint  
2. Connect `RithwikNavanandula/photo_detection`  
3. Confirm `render.yaml` → Apply  

**Option B — Manual Docker web service**  
1. New → Web Service → this repo  
2. Runtime: Docker  
3. Dockerfile path: `./Dockerfile`  
4. Add a persistent disk: mount `/var/data`, size ≥ 1 GB  
5. Health check path: `/api/check-auth`  
6. Set env vars (below)

### 3. Set secrets in Render

| Key | Notes |
|-----|--------|
| `OCR_SPACE_API_KEY` | Required for online OCR |
| `GMAIL_SENDER` | OTP login (Gmail address) |
| `GMAIL_APP_PASSWORD` | Gmail app password |
| `FLASK_SECRET_KEY` | Auto-generated by Blueprint |

Already set by `render.yaml`: `SESSION_COOKIE_SECURE=1`, `DB_PATH=/var/data/users.db`, `FLASK_ORIGIN=http://127.0.0.1:5000`.

### 4. After deploy

1. Open `https://<your-service>.onrender.com`
2. First boot seeds empty DB with:
   - `superadmin` / `super123`
   - `user1` / `user123`
3. **Change those passwords immediately**
4. Set `OCR_SPACE_API_KEY` (and Gmail OTP secrets if you use email login)

Persistent disk (`/var/data`) keeps SQLite across redeploys.
